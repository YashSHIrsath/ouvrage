# PAGE ARCHITECTURE

## Purpose

All pages must follow a consistent structure.

Pages are composed of reusable sections and layouts.

No page should implement custom layouts unless absolutely necessary.

---

# Standard Page Structure

Page
↓
PageLayout
↓
PageHeader
↓
Content Sections
↓
Call To Action
↓
Footer

---

# Public Layout

Components:

* Header

* Footer

# Section Rules

Every section must have:

* Section title
* Optional subtitle
* Content area
* Consistent spacing

---

# Responsive Rules

Desktop:

* Maximum width 1440px

Tablet:

* Responsive grid

Mobile:

* Single-column layout

---

# Animation Rules

Allowed:

* Fade in
* Slide up
* Counter animations

Avoid:

* Excessive movement
* Complex transitions

---

# Page Rules

* Reuse sections whenever possible.
* Use common spacing.
* Maintain visual hierarchy.
* Respect theme system.
